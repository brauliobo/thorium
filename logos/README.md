# Alacrium Artwork

The canonical editable sources are:

- `alacrium.svg`: application mark
- `alacrium_wordmark.svg`: wordmark for light backgrounds
- `alacrium_wordmark_white.svg`: wordmark for dark backgrounds
- `alacrium_ascii_art.txt`: terminal build banner

Run `infra/generate_alacrium_assets.sh` to regenerate platform-specific assets.
The `NEW`, `OLD`, and `STAGING` directories contain inherited Thorium and
Chromium artwork retained for source history and attribution; they are not the
canonical Alacrium identity.

Chromium artwork retains Chromium's BSD-style license. Inherited Thorium
artwork retains its original license and attribution.
